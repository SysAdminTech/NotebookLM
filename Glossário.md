# Glossário — DevOps no NotebookLM

## A

### Agile
Metodologia de desenvolvimento baseada em entregas rápidas, colaboração contínua e adaptação às mudanças.

### Ansible
Ferramenta de automação utilizada para configuração de servidores, provisionamento e gerenciamento de infraestrutura.

### API
Interface que permite comunicação entre sistemas, aplicações e serviços.

### AWS
Plataforma de cloud computing da Amazon amplamente utilizada em ambientes DevOps.

---

## B

### Backup
Cópia de segurança dos dados utilizada para recuperação em caso de falhas ou incidentes.

### Bash
Interpretador de comandos muito utilizado em sistemas Linux para automação e scripts.

### Build
Processo de compilação e preparação de uma aplicação para execução ou deploy.

---

## C

### CI/CD
Prática de Integração Contínua e Entrega Contínua que automatiza testes, builds e deploys.

### Cloud Computing
Modelo de fornecimento de recursos computacionais pela internet, como servidores, bancos de dados e armazenamento.

### Container
Ambiente isolado que empacota aplicação e dependências para execução consistente.

### Cybersecurity
Conjunto de práticas e tecnologias voltadas para proteção de sistemas, redes e dados.

---

## D

### Dashboard
Painel visual utilizado para monitoramento de métricas, logs e indicadores.

### Deployment
Processo de disponibilizar uma aplicação em ambiente de produção.

### DevOps
Cultura e conjunto de práticas que unem desenvolvimento e operações para acelerar entregas com automação e confiabilidade.

### Docker
Plataforma de containers amplamente utilizada em projetos DevOps.

---

## G

### Git
Sistema de controle de versão utilizado para rastrear alterações em código.

### GitHub
Plataforma de hospedagem de código-fonte e colaboração baseada em Git.

### GitLab
Plataforma DevOps que integra versionamento, CI/CD e gerenciamento de projetos.

---

## I

### IaC (Infrastructure as Code)
Prática de gerenciar infraestrutura utilizando código e automação.

### IAM
Gerenciamento de identidades e permissões em ambientes cloud.

### Infrastructure
Conjunto de servidores, redes, armazenamento e serviços que suportam aplicações.

---

## J

### Jenkins
Ferramenta de automação de pipelines CI/CD.

---

## K

### Kubernetes
Sistema de orquestração de containers utilizado para escalabilidade e gerenciamento de aplicações.

---

## L

### Linux
Sistema operacional mais utilizado em ambientes DevOps, cloud e servidores.

### Logs
Registros de eventos e atividades de sistemas e aplicações.

---

## M

### Machine Learning
Área da Inteligência Artificial focada em aprendizado automático a partir de dados.

### Monitoring
Processo de acompanhamento da saúde, desempenho e disponibilidade de sistemas.

---

## O

### Observability
Conjunto de práticas para análise profunda de métricas, logs e traces de aplicações.

---

## P

### Pipeline
Fluxo automatizado de processos como build, testes e deploy.

### Python
Linguagem de programação muito utilizada em automação, DevOps, IA e cibersegurança.

---

## S

### Script
Conjunto de comandos automatizados utilizados para tarefas repetitivas.

### Server
Computador ou serviço responsável por fornecer recursos para clientes e aplicações.

### SLA
Acordo de nível de serviço que define disponibilidade e desempenho esperados.

### SSH
Protocolo seguro utilizado para acesso remoto a servidores.

---

## T

### Terraform
Ferramenta de Infrastructure as Code utilizada para provisionamento de recursos cloud.

### Token
Chave de autenticação utilizada para acesso seguro a sistemas e APIs.

---

## V

### Virtual Machine (VM)
Máquina virtual que simula um computador dentro de outro ambiente computacional.

### VPN
Rede privada virtual utilizada para conexões seguras.

---

## Y

### YAML
Formato de arquivos muito utilizado em Kubernetes, Docker Compose e pipelines CI/CD.

---

# Conclusão

DevOps combina automação, colaboração, cloud computing, containers, integração contínua e monitoramento para acelerar a entrega de software com maior qualidade, segurança e escalabilidade.

O uso de ferramentas modernas como Docker, Kubernetes, Terraform, Jenkins e plataformas cloud permite construir ambientes eficientes e altamente automatizados, fundamentais no mercado atual de tecnologia.
